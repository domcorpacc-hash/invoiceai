# InvoiceFlow AI Starter

A working Next.js invoice-generator starter inspired by the workflow of AI/WhatsApp invoicing services.

## Run
1. Install Node.js 20+.
2. `npm install`
3. `npm run dev`
4. Open http://localhost:3000

## Included
- Responsive invoice dashboard
- Natural-language invoice parser endpoint
- Customer/contact fields
- Line items, GST, totals
- Invoice history in browser memory
- API route ready for persistence/PDF/WhatsApp integrations
